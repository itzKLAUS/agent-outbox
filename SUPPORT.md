# Support and sponsorship

For usage questions, open an issue with your Python version, operating system, sanitized integration details and a minimal reproduction. For bugs, include expected and actual behavior. Use SECURITY.md for vulnerabilities. Do not post production databases or credentials.

[Sponsor itzKLAUS](https://github.com/sponsors/itzKLAUS) to support open-source maintenance, regression testing and documentation. The repository's `.github/FUNDING.yml` enables the standard GitHub funding link. Contributions, careful reviews and useful issue reports are welcome too.

There is no paid SLA, promised response time, certification or guaranteed feature delivery. Sponsorship does not turn the MIT warranty disclaimer into a service agreement.
